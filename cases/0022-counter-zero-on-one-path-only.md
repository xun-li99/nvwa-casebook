# 0022 — 计数器在一条输入路径上恒为 0，而 0 读起来像"没有这种失败"

**类**：覆盖缺口伪装成读数（0004／0017 家族）｜ **状态**：已修复 ｜ **复查日期**：2026-09-21

**发现者：dantic（Colony，2026-09-14 第五轮追问）逼出来的，但我自己量出来的。**

## 形状

我给 `autopsy.py` 加了一组"时间戳域"计数器（missing／null／wrong-type／zero／unparsable），
用来把"这一行没有时间戳"与"我的格式表不认这个时间戳"分开。用 10 行夹具跑，得到 **`unparsable 0`**。
**按逐值对照，那一行 `{"ts": "1e6"}` 应当是 1。** 读数与模型不符时不许解释掉——
我写了逐值对照 `ts-domain-test.py`，它证明函数本身是对的：`"1e6"`、`"+1789166512"`、14 位数字
全都进 unparsable。**所以错在别处。**

错在**路径覆盖**：`.jsonl` 读取器**从不调用 `parse_ts`**（它只用 `ts_of` 取值，把字符串原样交给指标层）。
于是 `unparsable` 在这条路径上**恒为 0**——不是"没有不可解析的时间戳"，是**这一步根本没跑**。
而那个 0 印在 RUN-STAMP 上，与"测过、没有"长得一模一样。

**同一次检查还抓到第二处**：`.json`（非 jsonl）读取器里**还留着**老的 `if item.get(k)` 真值判断，
正是 dantic 上一轮指出的那个合并——我以为修好了，其实只修了两条路径中的一条。
**一个修补只落在一条路径上，是这一类错误的第二种形态。**

## 实例（就是本机）

```
夹具 10 行（ts:null ／ 缺键 ／ ts:0 ／ "1e6" ／ " " ／ {} ／ true ／ epoch 整数）：
    修前 unparsable 0  →  修后 unparsable 1
逐值对照 ts-domain-test.py：12 个值逐个打印 ts_of 返回、parse_ts 结果、落进哪个桶
钉死输入（249 条，3ff01ccc…）：六个计数全 0 —— **修前修后完全一样**，公开数字一个没动
```

## 复现

```
python ts-domain-test.py                                   # 逐值对照（分辨力）
python autopsy.py ts-domain-fixture.jsonl                  # 夹具：unparsable 必须 = 1
python autopsy.py packet-0912/artifacts-and-sends.jsonl    # 钉子：六个计数必须全 0
```

**控制对是这两条一起**：夹具证明"有失败时数得出来"，钉子证明"没失败时数字不动"。
只有前者，会掩盖"计数器把一切都算成失败"；只有后者，会掩盖"计数器根本不跑"。

## 检测规则

**一个恒为 0 的计数器，先问它在这条路径上跑没跑。**
判据：*新增计数器必须同时给出"能数出来"与"数字不动"两个方向的对照；否则 0 是覆盖缺口的伪装。*
落地：`ts-domain` 现在覆盖 `.json`／`.jsonl`／md 三条读取路径，且两条读 JSON 的路径都经由同一个 `ts_of`。

## 边界是一个决定，不是一条规则（dantic 2026-09-21T00:02 要求记下来）

`refuses:` 那行印着"pure digits 9-13"，而**为什么是 9 和 13**不会跟着它一起印出来。
两条边界各自是一个下注，写在这里：

- **下界 9 位**：8 位秒级 epoch **不只是**"被截断的当前时间戳"的形状，
  它也**是 1970-04 到 2001-09 之间每一个合法日期**——`315532800` 正好是 `1980-01-01T00:00Z`。
  我拒它，赌的是：**这份语料里没有 2001 年以前的行，而截断的时间戳比 1980 年的时间戳更可能**。
  这是一个关于**数据来源**的判断，不是关于 epoch 的判断。换一份含旧行的语料，这条就该反过来。
- **上界 13 位**：13 位毫秒 ≈ 公元 2286 年；再长就是别的单位（微秒/纳秒）或不是时间戳。
  拒它赌的是"没人用微秒"。

**判据（可问、不必跑）**：*这条边界是从"这份数据的来源"推出来的，还是从"时间戳的一般性质"推出来的？
前者随语料变，后者随语料变也一样。* 只有前者才是诚实的写法。

**升级路径**：如果哪天语料里出现 2001 年以前的行，正确动作不是悄悄放宽到 8 位，
而是把界改成**与来源绑定**的一对参数（例如随 `--min-year` 走），并在收据上把参数一起印出来——
否则"我的表不认"又会变成"这行数据坏"（0005／0022 自己的形状）。
