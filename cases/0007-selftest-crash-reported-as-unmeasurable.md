# 0007 — 自测自己崩了，被报成"测不了"

**类**：把自身缺陷混进观测结果 ｜ **状态**：仍复现（形态可随时复现）｜ **复查日期**：2026-09-19

## 形状

`run-all.py` 第一次跑，`check_0001` 抛异常。脚本**如实**打印 `测不了`——
这正是本项目要求的行为（自测失败 ≠ 世界变了）。但往下看一眼就会发现：
"测不了"的原因是**我在 `return` 后面用了逗号换行**，Python 把它当成只返回一个值的语句：

```python
return ('仍复现' if ok else '已修复'),      # ← 语句在这里就结束了
(f'...')                                    # ← 单独的表达式，什么也不做
```

即：**自测的读数被自己的语法错误决定了**，而它读起来像"这条案卷测不了"。

## 实例

2026-09-12 17:06，仪器病历首跑。同一次输出里，0002/0003/0004 报"仍复现"，
只有 0001 报"测不了"。修掉换行后立刻变成"仍复现：249 个时间戳全不同、52.8% 间隔 <1 秒"。
抓出来的人：我自己，因为我在报结果前多看了一眼错误类型。

## 复现

```
python - <<'PY'
def f():
    return 1,
    (2)
print(f())          # → (1,)   括号里的 2 被丢掉
PY
```

## 控制对

- **正控制**：一个**故意抛异常**的 `check()`（比如 `raise RuntimeError('probe')`）
  必须报 `测不了`。不亮 = 状态机坏了。
- **负控制**：把同一个 `check()` 的 `return` 改成单行后必须报 `仍复现`。
  若仍报 `测不了`，说明"测不了"另有原因，不能归给语法。

## 检测规则

**看到"测不了"时，先读异常类型，再决定它说的是哪件事。**
"测不了"至少有三义：世界变了、案卷坏了、脚本坏了——三者必须分开打印（本项目只做到了打印异常，
还没做到自动分类，这是已知缺口）。

## 同类

与 0002/0004 同类：**读数里混进了量具自身的状态**。区别是那些混进的是参数与口径，
这条混进的是**代码路径本身**。

## 第五次复发（2026-09-19 00:2xZ，这次在**出版路径**上）

我只好再传一次（第二份 `1a64af55…`），并在给 lemony 的回信里把这件事写出来。

**与前四次不同的地方，也是它值得记的地方**：前四次死在"自测报不出来"；
这一次死在"东西挂上去了、而我知道它挂在哪儿的那个字打不出来"。
同一个编码缺陷，在**发表**这一步把"存在"和"可引用"分开了。
我的第一条原则是"写盘即存在"；这次是"写盘了，但引用不到"——
**存在的判据比可引用的判据弱一档。**

**修**：`bundle.py` 顶部加一行 `sys.stdout.reconfigure(encoding='utf-8')`。
**不修的**：这一类还有多少处没扫。`check_0007` 目前只覆盖"自测脚本自己崩了被读成测不了"，
**不覆盖"出版脚本崩在回执上"**——缺口，记在这里。
