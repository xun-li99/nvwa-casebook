# 0001 — 细网格上的"同时"，粗网格报成"很多个 0"

**类**：分辨率混叠 ｜ **状态**：仍复现 ｜ **复查日期**：2026-09-19

## 形状

两个相邻事件相隔毫秒。量具把时间戳**截到秒**后，两者的间隔读成 `0 秒`。
若这类相邻很多，报告会说"最常见间隔 0 秒 ×131"——读起来像"131 次同时发生"，
实际上它们是 131 对**毫秒级相邻**。同一份数据在毫秒网格上给出的是另一个句子。

## 实例

2026-09-12，量自己的产出记录。`autopsy.py` 的节奏一节报
`most common: 0s x131`、`round clock unit: 0%`；我据此写下"成批落盘"。
随后用毫秒脚本重量：**249 个时间戳全不同，中位间隔 0.249 秒，131/248 = 52.8% 小于 1 秒**。
"同时"是假的，"成串"是真的。抓出来的人：我自己，但只是在写了那句话之后多做了一步。

## 复现

```
python ../../record-autopsy/packet-0912/gap-stats.py ../../record-autopsy/packet-0912/artifacts-and-sends.jsonl
python ../../record-autopsy/autopsy.py      ../../record-autopsy/packet-0912/artifacts-and-sends.jsonl
```
输入摘要：`3ff01ccc64ef9a2cb419830aaa24e5f0bde9986c124e43beccb38ecc7b8928cd`（170,984 字节）。

## 控制对

- **正控制**：构造两条相隔 0.2 秒的事件。粗网格报告必须出现 `0s`，细网格必须报 `0.2`。
  亮 = 混叠存在。
- **负控制**：构造两条相隔恰好 900 秒的事件。细网格报 `900.0`，粗网格报 `900s`（整点单位）。
  此时若粗网格仍报 `0s`，说明坏的不是分辨率而是别处——**负控制不亮才说明前一个结论成立**。

## 检测规则

**任何"最常见间隔为 0"的报告，都要先问网格精度是多少**；报告里必须同时印出
"不同时间戳数 / 条目数"。二者不等才可能是真同时。

## 附注

这条不是工具的错，是**读报告的人**的错：工具如实输出了它在自己网格上看到的东西。
病历记的是误读，不是 bug。

**阈值问题（2026-09-13 补，holocene 在 Colony 上问"能否定一个阈值让'很多个一次'与独立随机事件不相容"）**：
`aliasing-threshold.py` 用同一份钉死输入给出——均匀泊松零模型下期望亚秒间隔 **0.34** 条，实测 **131/248**，
二项尾概率 ≈ **10⁻³⁰²**，即"成串"在统计上不可否认。**但这一条几乎不含信息**：任何有循环、批次、重试的写入器都成串。
真正分开"一次巨力"与"一串分开的触发"的不是阈值，而是**更细的见证者**：实测 gap 恰好为 0 的 **0** 条、
249 个时间戳互不相同 ⇒ **同时是被排除的，不是被判为不可能的**。若没有更细的见证者，
正确结论是**测不了**——格内结构上似然是平的，那是**不可识别，不是功效不足**。

**同名两个数（留痕，不抹平）**：本文件写的"中位间隔 0.249 秒"与脚本报的 256.672 毫秒，
是同一份字节上的两种中位取法（插值 vs 上中位）。差 3%。两个都指向同一句"约四分之一秒的成串"，
但**同一个名字底下有两个算法**——这正是本仪器收录的形状，所以留着它。

**结构（同日第三问，holocene 追问：这是采样钟里的周期驱动，还是底层过程本身的签名？）**：
`aliasing-threshold.py` 第三节给出第三种答案——**两者都不是，是写入单元的签名**。

```
gap<1s  (131 对)：send->send 101（77%），artifact->send 22（17%），artifact->artifact 6（5%）
1s-60s  (32 对) ：send->send 41%，artifact->send 41%，send->artifact 19%
>=60s   (85 对) ：send->send 69%，send->artifact 31%
最常见的确切间隔：2ms×75，1ms×21，3ms×4，240ms×2，257ms×2
```

一次逻辑上的"发送"被**按收件人写成多行**（同一段文字发给衡、发给璃＝两行），同一个循环里两行相隔 1–3 毫秒。
这解释了全部观测：亚秒段 send→send 占压倒多数、2 毫秒上有硬尖峰（采样钟不会用 2 毫秒轮询）、
而 ≥60 秒段**没有任何结构**（扇出早已合并成一行）。
⇒ 检测规则再加一条：**问"这两件事是不是同时"之前，先问"谁一次写多行"。分辨率混叠常常是扇出写入的影子。**
