# 0016 — 观测字段长在被哈希承诺的身份里（公开语料上的量化）

**类**：环境观测混进身份（0010 的语料级版本）｜ **状态**：仍复现 ｜ **复查日期**：2026-09-19

**实例来源：ainglish.org 的公开证据语料（1301 条测量）。**
**形状提出者：lemony（0010）。本条把那个 1 个实例变成一个有分母的比例。**

## 形状

manifest 是**被哈希承诺的设计**：铸出承诺后再改一个字节就归档不了。
而公开语料里，**超过三分之一的 manifest 里装着"观测"字段**——传输故障数、缺席格数、截断格数。
这些数**只有跑完才知道**。它们进了身份，就等于把"这次跑得顺不顺"写进了"这是哪个实验"。

lemony 的 0010 是这条形状的**一个事故**（发出哈希 ≠ 承诺哈希，归档被拒）。
本条问的是：**这个形状在公开语料里占多少。**

## 实测（2026-09-12，只读公开 API，两个独立切片）

| 指标 | 切片 A：列表前 40 条 | 切片 B：600 条里每 15 取 1（40 条） |
|---|---|---|
| 取到 manifest | 40/40 | 40/40 |
| **manifest 含观测类字段** | **15/40 = 37.5%** | **15/40 = 37.5%** |
| 声明 `estimand` | **0/40 = 0%** | **3/40 = 7.5%** |
| `models` 带精度（`@q4_k_m` 等） | 5/40 = 12.5% | 11/40 = 27.5% |

**第一条在两个切片上一致（37.5%）**，所以"观测字段长在身份里"是语料的性质，不是某一段的性质。
**第二条在两个切片上差了 7.5 个百分点**：切片 A 的 0% 是**列表顺序**的属性。
切片刻画的是切片，不是语料——这正是本病历 0004 条的病，这次犯在别人的数据上，
所以两个数都留在这里，不取平均、不取"更漂亮"的那个。

观测字段的典型取值（切片 B 的命中样本）：
`transport_faults`、`transport_truncations`、`max_transport_fault_cells`、
`max_absent_cells`、`max_truncated_cells`。
注意后半三个是**容忍度**（设计的一部分），前半两个是**观测**（跑完才知道）。
**同一个 manifest 里两种东西并存，正是"容忍度声明了、却是观测值在决定身份"的现场。**

## 复现

```
python run-all.py --only 0016          # 真去公开 API 抽样重算，约 45 秒
python packet-0912/ainglish-manifest-audit.py 40      # 切片 A（约 80 秒）
python packet-0912/ainglish-manifest-audit2.py 3      # 切片 B（约 85 秒）
```

## 控制对

- **正控制**：合成一个含 `transport_faults` 的 manifest → 检测器必须命中。
- **负控制**：合成一个只有 `metric/models/seed` 的 manifest → 检测器必须不命中。
  任一不符即"案卷坏了"（检测器有毛病，与语料无关）。
- **外加一条纪律**：check 必须**同时报出样本量与切片方式**。
  只报比例不报切片，等于把切片冒充语料。

## 检测规则

**铸承诺之前，把 manifest 的每个字段问一遍："这个值是设计的，还是跑完才知道的？"**
跑完才知道的，一律进"可复现层"（公布、可比），不进"身份层"（哈希相等）。
